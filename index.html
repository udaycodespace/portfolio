01 / About

Building software is one thing. Running it in the cloud is another.

A year ago I was deep in React and Node.js code. Today I split my time between Azure infrastructure and open source, learning what happens after the MVP stage — the unglamorous part nobody posts about.

"Give me a codebase I've never seen and I'll spend a weekend finding my way around it — not because it's easy, but because that's how I actually learn."

I'm a Technology Consultant at Meteoros Automation, working on Azure VM provisioning, cloud lab environments, and QA support. Before that I built full-stack features for a Frappe + React ERP at Inkers Technology, and earlier ran SVDS, a freelance web studio I opened, grew for a quarter, and closed on my own terms once it had done its job.
